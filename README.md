# ConnectX Call Center Network Design

## Overview

This repository contains my Computer Networks coursework project, which involves designing and implementing a network for ConnectX Call Center, located in Colombo 5, using Cisco Packet Tracer.

The project includes the network topology, device configurations, design assumptions, and supporting documentation used to create a functional and scalable network infrastructure for the organization.

## Repository Contents

* `CiscoMap.pkt` – Cisco Packet Tracer project file
* `ConnectXreport.pdf` – Project report

## Features

* VLAN implementation
* IP addressing scheme
* Routing configuration
* Network segmentation
* End-device connectivity
* Basic network security considerations

## Software Used

* Cisco Packet Tracer

## How to Use

1. Download the repository files.
2. Open the `.pkt` file using Cisco Packet Tracer.
3. Review the report for detailed explanations of the network design and configurations.
